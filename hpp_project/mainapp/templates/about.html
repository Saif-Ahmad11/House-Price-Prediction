Project Overview

The House Price Prediction System is developed using Python, Django, Bootstrap and Machine Learning.

Users can enter housing details such as income, house age, rooms, bedrooms, population, latitude, and longitude to predict estimated house prices.

The prediction model has been trained using real housing data and integrated into a modern web application.
